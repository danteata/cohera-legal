# cohera-legal

Legal pages for the **Cohera** impromptu-speaking app, served by GitHub Pages.

- Privacy policy — <https://danteata.github.io/cohera-legal/>

The privacy policy is written from what the app actually does, not from a
template, and it must be kept in step with the Play Console **Data Safety**
form. The answer most often got wrong: transcript text sent to a third-party
API counts as *shared*, not merely *collected*, even though the processor does
not retain it.

Source of truth for the underlying facts: `store-listing/PRIVACY.md` in the
app repository.
